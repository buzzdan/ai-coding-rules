# go-mini

## Commands

- `task build` — compile all packages and `bin/svc`
- `task test` — run unit tests
- `task test:race` — run unit tests with `-race`
- `task lint` — run golangci-lint
- `task lintwithfix` — golangci-lint with `--fix`

Go 1.24, stdlib only. Tests use the standard `testing` package.
